# Technical Architecture
Initial: npm workspaces, Next.js + TypeScript web, Expo/React Native + TypeScript mobile, shared TypeScript contracts. Supabase is planned but not connected.
Planned boundaries: identity, knowledge governance, Panchang, astrology, AI orchestration, expert bookings, music, community/live sessions, billing and notifications.
Security: never expose service-role secrets to clients; validate and authorise on the server; audit knowledge publication and financial events.
