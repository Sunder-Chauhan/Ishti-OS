# Ishti-OS
Local-first monorepo for YUGON — an authentic spiritual ecosystem inspired by India's timeless traditions. Rooted in Tradition. Connected to Today.

## Requirements
Node.js 22 LTS, npm 10+, Git.

## Run on Windows PowerShell
```powershell
cd spiritual-OS
npm install
npm run dev:web
# In another terminal:
npm run dev:mobile
```
Open the local URL printed by Next.js. For mobile, use Expo Go or an Android emulator.

Milestone M01 provides the monorepo, web/mobile starter shells, shared platform definitions and governance docs. Supabase, AI, religious content, payments, chat and streaming are not connected yet.

Religious content must only be served from approved, rights-cleared sources. AI must not invent mantras, ritual steps, samagri lists or auspicious timings.
