# Ishti-OS
Local-first monorepo for ISHTI — an authentic spiritual ecosystem inspired by India's timeless traditions. Rooted in Tradition. Connected to Today.

**Official Public Brand:** ISHTI  
**Internal Repository Codename:** spiritual-OS  
**Brand Positioning:** A modern spiritual ecosystem rooted in Indian wisdom.

## Requirements
Node.js 22 LTS, npm 10+, Git.

## Run on Windows PowerShell
```powershell
cd spiritual-OS
npm install
npm run dev:web
# In another terminal:
npm run dev:mobile
```
Open the local URL printed by Next.js. For mobile, use Expo Go or an Android emulator.

Milestone M01 provided the monorepo, web/mobile starter shells, shared platform definitions and governance docs. Milestone M02 establishes the secure Supabase backend, RLS policies, DPDP Act 2023 consent tracking, and early access flow.

Religious content must only be served from approved, rights-cleared canonical sources. AI must not invent mantras, ritual steps, samagri lists or auspicious timings.
